Contact
=======

Report reproducible problems through the
`GitHub issue tracker <https://github.com/Kuanhao-Chao/OpenSpliceAI/issues>`_.
Include the command, source/package version, environment versions, input schema,
error message and a small shareable example. Do not include private genomes or
identifiable sample data. For collaboration contact ``kuanhao.chao@gmail.com``.
