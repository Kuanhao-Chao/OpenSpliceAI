Pretrained models
=================

Select the model trained for your species/annotation and the matching total context
(80, 400, 2000 or 10000 bases). Each context has five seed checkpoints; placing
only those compatible files in a directory enables probability ensembling.
Model weights are separate from the package wheel. Download links below retain
the published model locations. Use the release's training provenance when
interpreting comparisons; larger contexts cost more inference resources.
